Detailed Description

template<typename T>
requires std::is_arithmetic_v<T>
class array_randomizer< T >

Random number generator (rng) class for filling arrays.

Template Parameters
TValue type of rng and the requirement of arithmetic type.
Note
This class uses std::mt19937_64 as the random number generator.
